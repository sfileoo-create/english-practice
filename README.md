# English Practice

Telegram Mini App для тренировки английского: времена, слова, разговорные фразы, неправильные глаголы.

- `exercises.js` — все упражнения и словарик (сюда добавляются новые темы)
- `app.js` — логика приложения
- `style.css` — оформление

## Личная практика

- «Времена»: 278 заданий, темы можно смешивать.
- «At / In / On»: 100 заданий о времени, датах, случаях без предлога и устойчивых выражениях. Британские и американские варианты явно отмечены.
- «Мой словарь»: добавление слова и перевода, тренировка и сохранение прогресса. В Telegram данные сохраняются в CloudStorage с локальной резервной копией; в браузере — локально.

## Озвучка

Используются только готовые записи Kokoro (af_heart, скорость 0.95), без системных голосов и сторонних словарных записей. Если нужной записи ещё нет, кнопка звука недоступна. Это также относится к новым личным словам, для которых запись пока не подготовлена.

После изменения `exercises.js` GitHub Actions собирает тексты и создаёт новые MP3. Общая функция `questionSpeech` исключает подсказки и вариант «Без предлога» из произносимой фразы.

Локальный просмотр: `python3 -m http.server 8765 --bind 127.0.0.1`. Список текстов: `node tools/collect_texts.js > texts.json`.

Правила предлогов сверены с [British Council](https://learnenglish.britishcouncil.org/grammar/a1-a2-grammar/prepositions-of-time-at-in-on) и [Cambridge English Grammar Today](https://dictionary.cambridge.org/grammar/british-grammar/at-on-and-in-time).
